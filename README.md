# maratona-sbc-2026-serra

Site informativo da Sede Regional Serra da Maratona SBC de Programação 2026.

## Arquivos principais

- `index.html`: página principal do site.
- `documentos/orientacoes_inscricao_maratona_sbc_2026_sede_serra.pdf`: PDF com orientações de inscrição.
- `documentos/orientacoes_inscricao_maratona_sbc_2026_sede_serra.typ`: fonte em Typst do documento de orientações.

## Formulários internos do Campus Serra

Antes da inscrição oficial no ICPC e do pagamento no ECOS da SBC, estudantes do Ifes Campus Serra devem preencher um dos formulários internos abaixo:

- [Cadastro Interno: Equipes da Maratona de Programação 2026 - Ifes Campus Serra](https://forms.gle/ADKfr7eUaYhuusRp7)
- [Cadastro de Maratonistas Individuais: Maratona de Programação 2026 - Ifes Campus Serra](https://forms.gle/SQ9bSPJiRVybjCnT7)

O primeiro formulário é para equipes já formadas, com 3 integrantes ou 4 integrantes quando houver reserva. O segundo formulário é para estudantes que querem participar, mas ainda não conseguiram formar uma equipe.
